## 📁 Project Summary

As a data analyst, I explored the Coursera Course Dataset to uncover key insights about course popularity, difficulty, and organizational performance. Using Python and Pandas, I:

  1. Cleaned and prepared the data for analysis.

  2. Visualized trends in enrollment, ratings, and difficulty levels.

  3. Provided actionable insights on Coursera’s content strategy and learner preferences.


## 📊 Dataset

- [Coursera Course Dataset](https://www.kaggle.com/datasets/siddharthm1698/coursera-course-dataset)

## 📌 File Descriptions

- `M4S3_Project2.ipynb` — main notebook containing all the analysis and visualizations.
- `coursea_data.csv` — dataset used in the notebook.
- `README.md` — project overview and documentation.
